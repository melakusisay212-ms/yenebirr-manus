# Yene Birr 3.1 (የኔ ብር)

Ethiopian calendar personal finance tracker.

## 3.1 highlights
- **Transfers** between accounts (not income/expense)
- **Saving goal** accounts with monthly & yearly progress
- **ያበደርኩት / የተበደርኩት** (money lent / borrowed) in Settings
- **Analysis**: month-on-month income/expense comparison + extra insights
- Same app ID → updates existing install without data loss

## 3.0 highlights
- Category Ranking analysis
- Month navigator on Analysis
- Green default theme + Noir dark theme
- Ledger day groups with daily totals
- Edit transactions & accounts

## Build APK
Push to GitHub → Actions → Build Android APK → download `yenebirr-debug-apk`

App ID: `com.melaku.yenebirr` (keep for update)
